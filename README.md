# メロモンクエスト 〜音符と音の冒険〜 🎹🐲✨
**by Yuya Ando**

読譜（譜読み）と聴音（音当て）をゲーム感覚で楽しく学べる本格RPG風ピアノ学習Webアプリです！

公開URL: https://yuya-labo.github.io/melomon-quest/

---

## 🌟 特徴
- **あそべる勇者**: 男の子勇者 ⚔️ / 女の子勇者 🛡️ を選んで冒険に出発！
- **鍵盤**: 1.5オクターブ鍵盤（白鍵12鍵＋黒鍵8鍵、リアルなグランドピアノ音色）
- **楽譜表示**: 楽典に完全準拠した五線譜（ト音記号・ヘ音記号、高音もはみ出さないテロップ表示）
- **演出**:
  - 森のパララックス横スクロール背景 ＆ 横向き歩行アクション
  - 剣による斬撃（ズバッ！） ＆ 盾による鉄壁ガード（ガキィン！）
  - 敵の弾道攻撃（右から左へ飛来）
  - 仲間モンスターのパレード隊列（勇者の後ろをついて行進！）
  - 5連続正解の魔法キラキラ演出 ＆「まほうの薬」ゲット（タップで時間+5秒回復！）
  - 村防衛ステージ（被弾・大炎上ゲームオーバー演出）
  - ゲーム終了時の仲間モンスター大型ビジュアル表示（集まったモンスターたちを確認！）
  - ゲーム終了時の苦手克服・復習コーナー（間違えた問題の五線譜・音名・試聴機能！）
- **BGM・効果音**: 壮大なオーケストラ風冒険テーマ、クリスタル調タッチ音（ピロン♪）、迫力の効果音

---

## ⚔️ ゲームモード

### 1. ⚔️ 修行モード (全20問)
- **こうげき練習 (ト音記号)**: 正解してドラゴンに剣の一閃！
- **ぼうぎょ練習 (ヘ音記号)**: 村の前で仁王立ちし、火の玉を盾でガード！
- **じっせん練習 (ミックス)**: ト音記号とヘ音記号の実践特訓！

### 2. 🌲 冒険に出発 (1分チャレンジ)
- **敵をたおす**: 次々に現れるモンスターを討伐して進む冒険！
- **攻撃をふせぐ**: 襲撃から村を守り抜く防衛バトル（HP10制）！
- **仲間をあつめる**: 5問ごとにモンスターを倒して仲間にしよう（オオカミ、妖精、魔女、ドラゴン、大魔王）！

### 3. 🏆 冒険のきろく（モード別ランキング）
- **モード別ランキング集計**: 仲間集め・敵討伐・村防衛・修行モードそれぞれのTop10とメダル表示
- **最高到達仲間モンスター図鑑**: 過去に仲間になったモンスターコレクション一覧
